# Painted Treasury expansion

Adds 20 individually generated transparent watercolour paintings: Moonflower Lanterns, Crescent Crowns, Poet’s Inkwells, and Celestial Folios, each in Bronze, Silver, Gold, Platinum and Emerald.

Together with the five Moonlit Tea paintings there are 25 images across five selectable collections. The gallery at /treasury/catalogue?collection=moonlit-tea loads one family at a time.

PalaceGift selects the corresponding family from its existing gift kind and uses the owned or preview tier to select the correct painting. The same component is used by gift cards and profile showcases. The imagery changes only the visual presentation; no gift definitions, ownership records, rankings or badge unlock rules are changed.

Prompts and saved asset paths are recorded in PAINTED_TREASURY_PROMPTS.json. All images use the built-in image generation tool. Complete silhouettes are displayed with object-fit: contain and padding; no extra object frames or colour filters are applied.
